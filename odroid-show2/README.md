# Hardkernel ODROID-SHOW2

ATmega328P (16 MHz, 3.45 V) with a 2.2 in 320 × 240 TFT (Tianma TM022HDH26,
ILI9340C), CP2104 USB serial, a LiPo charger (XC6802, 4.2 V, 500 mA) and
battery connector, power switch, three buttons (PD7, PC0, PC1) and three
LEDs (PD3, PD4, PD6) on an 83 × 48 mm board. Module id `HardkernelOdroidShow2ModuleID`.

![The part](preview.png)
